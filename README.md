# Mama Mia Ristorante 
An elegant Italian restaurant website, Michelin star inspired concept.
The project focuses on a clean, minimal editorial layout and a bespoke user experience.

## Key Features
* 5 Main Pages: Home, Menu, Reward, About Us, and Order
* Interactive Menu: Minimalist layout featureing hover dish previews
* Concierge Order Drawer: A sleek slide out panel for seemless ordering
* Loyalty Program: Offers Membership using Email

## Tech Stack
* Frontend: HTML5, CSS3 / Tailwind CSS, JavaScript
